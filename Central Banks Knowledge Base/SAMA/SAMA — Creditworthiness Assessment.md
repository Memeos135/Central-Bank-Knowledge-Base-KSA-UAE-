# Creditworthiness Assessment

This node covers the responsible-lending duty on creditors to assess a consumer's creditworthiness and repayment capacity using a documented, board-approved methodology reviewed annually, applied and evidenced in the finance file before finance is granted. It requires consumer-consented credit record enquiry, written disclosure of other credit obligations (including informal or employer loans), and use of financial models that account for a defined minimum set of basic living expenses plus existing monthly credit commitments. It binds creditors under the SAMA responsible-lending principles when granting consumer finance.
