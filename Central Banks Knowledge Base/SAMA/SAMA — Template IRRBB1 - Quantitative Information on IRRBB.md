# Template IRRBB1 - Quantitative Information on IRRBB

A quantitative Pillar 3 template under SAMA's disclosure framework requiring banks to report IRRBB exposure values — changes in economic value of equity (ΔEVE) and net interest income (ΔNII) — under the prescribed Basel interest rate shock scenarios. It binds banks in scope of the IRRBB standard and is paired with the qualitative Table IRRBBA. Values are computed using the bank's own internal measurement system, with reference to the relevant SAMA IRRBB circular.

**Regimes:** banking prudential, governance/risk
