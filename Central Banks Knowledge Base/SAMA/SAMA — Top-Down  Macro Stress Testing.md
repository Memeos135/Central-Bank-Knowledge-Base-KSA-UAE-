# Top-Down / Macro Stress Testing

A section of SAMA's Rules on Stress Testing describing supervisory (top-down/macro) stress testing, distinct from banks' own bottom-up tests. It sets out SAMA's three-component approach: using banks' submitted bottom-up results, directing banks to run SAMA-specified sensitivity or scenario tests and report the outcomes, and SAMA running its own system-wide tests on macroeconomic and collected banking data. The reporting obligations bind banks; the accompanying Q&A confirms SAMA will not formally release its top-down results, though high-level findings may be shared in bilateral supervisory meetings.

**Regimes:** governance/risk, banking prudential
