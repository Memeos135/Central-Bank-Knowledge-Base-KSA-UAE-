# Change Security Requirements

Short sub-section of the SAMA IT Governance Framework requiring cyber security requirements to be defined and fully tested in a test environment for all changes to information systems, so vulnerabilities are identified and mitigated before production release. It expressly ties the change management process back to the SAMA Cyber Security Framework for defining, testing and implementing those security requirements. Applies to Member Organizations.

**Regimes:** governance/risk
