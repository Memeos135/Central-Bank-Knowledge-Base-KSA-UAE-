# SAMA Cyber Security Framework

Node for the SAMA Cyber Security Framework as cross-referenced by the IT Governance Framework and related circulars, notably where change management must apply cyber security requirements before moving changes to production. It is the reference instrument for cyber security control requirements and maturity assessment across SAMA Member Organizations, sitting alongside but distinct from IT governance controls.

**Regimes:** governance/risk
