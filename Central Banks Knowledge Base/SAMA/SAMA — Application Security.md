# Application Security

A control domain within the technology-security part (section 3.3) of SAMA's Cyber Security Framework addressing cyber security requirements for applications used by Member Organizations. It sits within the framework's policy, roles-and-responsibilities and maturity-model structure, under which controls must be defined, approved, implemented, monitored and periodically evaluated. Open the source for the specific application security control considerations, which are not reproduced in this extract.
