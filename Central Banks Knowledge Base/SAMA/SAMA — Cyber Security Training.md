# Cyber Security Training

Node within the SAMA Cyber Security Framework covering cyber security awareness and training expectations, situated alongside the framework's maturity model, cyber security policy content requirements and the allocation of cyber security roles and responsibilities. It requires that relevant stakeholders be made aware of cyber security expectations and expected behaviour through a defined awareness programme, with the Board holding ultimate responsibility (including budget and approvals). It binds Member Organizations supervised by SAMA, and is assessed against maturity levels (target levels require formalised, documented and demonstrable controls).

**Regimes:** governance/risk, other
