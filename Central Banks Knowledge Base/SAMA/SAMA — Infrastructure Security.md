# Infrastructure Security

A control domain of SAMA's Cyber Security Framework (section 3.3.8) requiring Member Organizations to define, approve and implement cyber security standards for infrastructure components, monitor compliance with those standards and periodically measure their effectiveness. The aim is that all infrastructure-level cyber security controls are formally documented and supervised. It binds SAMA-supervised Member Organizations and is assessed against the framework's maturity model.

**Regimes:** governance/risk
