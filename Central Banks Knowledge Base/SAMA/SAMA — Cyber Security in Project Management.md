# Cyber Security in Project Management

This node sets the requirement that cyber security be embedded in project management and project governance within a Member Organization. Controls include integrating cyber security into the project methodology, including cyber security objectives in project objectives, involving the cyber security function across all project phases, performing a risk assessment at project start, registering and tracking cyber security risks in the project risk register, allocating responsibilities, and obtaining an independent internal or external cyber security review. It is assessed against the framework's maturity model and binds SAMA-supervised Member Organizations.

**Regimes:** governance/risk
