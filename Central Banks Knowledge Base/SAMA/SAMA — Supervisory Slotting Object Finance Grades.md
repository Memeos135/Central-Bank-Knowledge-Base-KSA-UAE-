# Supervisory Slotting: Object Finance Grades

Concept node for the supervisory slotting criteria applied to object finance (OF), a sub-class of specialized lending, where banks unable to estimate PD map internal grades to five supervisory categories (strong, good, satisfactory, weak, default) with prescribed risk weights and expected loss amounts. The linked minimum requirements govern rating structure, use of current and material information, and demonstrating that the internal-to-supervisory mapping is consistent. Binds SAMA-supervised banks using IRB for specialized lending exposures.

**Regimes:** banking prudential, governance/risk
