# Cyber Security Architecture

A control domain of SAMA's Cyber Security Framework (section 3.3.4) requiring Member Organizations to define, follow and periodically review a cyber security architecture that sets out the cyber security requirements for the organisation. Associated expectations include formal approval of the architecture, qualified cyber security architects, and security-by-design principles for developing controls. Maturity of compliance is assessed against the framework's six-level cyber security maturity model.

**Regimes:** governance/risk
