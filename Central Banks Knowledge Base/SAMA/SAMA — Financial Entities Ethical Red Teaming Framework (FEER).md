# Financial Entities Ethical Red Teaming Framework (FEER)

SAMA circular adopting the Financial Entities Ethical Red Teaming (FEER) framework, a regulatory framework for simulating realistic cyber attack scenarios to test the resilience of financial institutions' core systems. SAMA states it will run periodic FEER-based tests on financial institutions and expects them to conduct independent, periodic testing and remediation in line with the Cyber Security Framework. Addressed to banks operating in the Kingdom, Saudi Payments and licensed payment companies, and insurance/reinsurance entities; the framework itself is circulated separately to compliance departments.

**Regimes:** governance/risk, payments
