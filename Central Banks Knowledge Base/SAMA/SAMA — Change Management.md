# Change Management

A control domain of SAMA's Cyber Security Framework requiring Member Organizations to define, approve and implement a change management process covering changes to information assets, with monitored compliance and periodically measured control effectiveness. It sets expectations on impact assessment and classification of changes, security testing (penetration testing and internal/external code review or equivalent assurance), business-owner, cyber security function and Change Advisory Board approvals, segregation of development/test/production, emergency change procedures and fall-back/roll-back. It binds SAMA-supervised Member Organizations and feeds into infrastructure security controls.

**Regimes:** governance/risk
