# NVR Server Specifications

Technical specification tables from SAMA's branch/facility physical security requirements covering the network video recorder (NVR) server and PTZ IP cameras used in CCTV installations. It sets minimum retention (continuous recorded footage over a defined day range at stated frame rate and resolution), RAID/storage, redundancy, compression, platform and integration (PSIM, ONVIF, open API) parameters, plus PTZ optical/digital zoom, pan-tilt, illumination and environmental tolerances. It binds supervised entities operating branches/facilities in KSA as a physical-security control baseline for their premises surveillance estate.

**Regimes:** governance/risk, other
