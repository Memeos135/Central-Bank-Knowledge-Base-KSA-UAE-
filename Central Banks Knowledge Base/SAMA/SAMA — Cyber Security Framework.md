# Cyber Security Framework

A cross-reference concept linking the Cyber Resilience Fundamental Requirements to SAMA's broader Cyber Security Framework, and the source of the defined terms used (cyber security governance, cyber security incident, incident management, cyber security policy, cyber security risk), several drawn from NIST glossary definitions. It matters for scope questions about which instrument governs a given entity: the lighter Fundamental Requirements for early-stage/sandbox entities versus the fuller Cyber Security Framework for established supervised entities.

**Regimes:** governance/risk
