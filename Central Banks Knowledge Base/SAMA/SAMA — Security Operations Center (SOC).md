# Security Operations Center (SOC)

Concept node for the security operations centre function as referenced across SAMA cyber security requirements, covering monitoring and detection capability that feeds the maturity assessment and incident handling expectations. It is a capability/control concept rather than a standalone rulebook, assessed through the framework's maturity levels (0–5) and the associated control considerations. Applies to Member Organizations subject to the SAMA cyber security regime.

**Regimes:** governance/risk
