# IP Camera Specifications

The camera products section of SAMA's CCTV/physical security requirements, specifying that surveillance cameras be Full HD IP-based, PoE-powered, ONVIF-compliant and supported by an open published API, with detailed design criteria for fixed megapixel cameras and general encoding, streaming, security and time-synchronisation requirements. It also addresses installation conditions: protective/vandal-proof enclosures, outdoor ingress protection ratings, siting for lighting conditions, and lockable racks in secure rooms aligned to branch security zoning. It binds supervised entities (and their contractors) deploying branch surveillance systems in KSA.
