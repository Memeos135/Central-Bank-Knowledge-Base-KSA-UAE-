# Cyber Security Framework (CSF)

Cross-cutting reference to SAMA's Cyber Security Framework, the baseline cybersecurity governance and control regime for entities supervised by SAMA. It is the parent framework that the Cyber Threat Intelligence Principles and the ethical red teaming circular build on, with SAMA expecting Member Organizations to test and develop their systems against CSF requirements. Binds all SAMA-regulated Member Organizations (banks, insurers, payment and finance companies).

**Regimes:** governance/risk
