# Cyber Security Audits

Sub-domain 3.2.5 of the SAMA Cyber Security Framework, covering independent cyber security auditing of the Member Organization's controls as a third line of assurance, distinct from management-led cyber security reviews. It connects to board-level accountability for cyber security and to the maturity model used by SAMA to assess and compare Member Organizations. Binds SAMA-supervised Member Organizations and their internal audit function and Board.

**Regimes:** governance/risk
