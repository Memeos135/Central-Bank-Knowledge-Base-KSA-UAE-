# Net Present Value Analysis

Node setting out the requirement that banks compare the economic value of a proposed restructuring against the alternatives (note sale, enforcement, insolvency) using net present value analysis before settling on a resolution approach. It explains the NPV mechanics, the use of the bank's standard risk-adjusted discount rate or alternatively the original effective interest rate used for IFRS 9 provisioning, and the parameters to model under each option (new tenor and pricing, collateral haircuts and litigation costs, insolvency costs and timelines). It also requires banks to revisit the chosen approach when new or contradictory borrower information emerges.

**Regimes:** governance/risk, banking prudential
