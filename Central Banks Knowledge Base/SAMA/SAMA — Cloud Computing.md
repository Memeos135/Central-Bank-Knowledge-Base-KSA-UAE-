# Cloud Computing

A third-party cyber security control governing Member Organizations' use of hybrid and public cloud services (expressly not private/internal cloud), requiring a cloud computing policy and process with monitored, periodically evaluated controls. Substantive conditions include prior SAMA approval before using cloud services or signing with a provider, a contract containing cyber security requirements, in-principle data location within Saudi Arabia (with explicit SAMA approval for offshore), no secondary use of the Member Organization's data, provider security controls per risk assessment, logical data segregation, business continuity alignment, rights of review, audit and examination, and exit arrangements. It binds SAMA-supervised Member Organizations and is read with the outsourcing control and SAMA's outsourcing circular.
