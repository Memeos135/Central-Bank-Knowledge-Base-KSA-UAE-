# System Change Management Domain

Domain 3.4 of the IT Governance Framework governs changes to information assets (applications, software, devices, data), requiring an approved change management policy and process covering requirement definition and approval, severity and priority, risk and impact assessment, development, testing, release, and configuration monitoring. It mandates Change Advisory Board endorsement before production deployment, prior cyber security function review (cross-referencing the SAMA Cyber Security Framework), and post-implementation review, documentation and root cause analysis for emergency changes. It binds SAMA Member Organizations and their IT, cyber security and audit functions.

**Regimes:** governance/risk
