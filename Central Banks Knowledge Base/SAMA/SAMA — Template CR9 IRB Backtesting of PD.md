# Template CR9: IRB Backtesting of PD

A Pillar 3 template requiring annual backtesting disclosure comparing probabilities of default used in IRB capital calculations against realised obligor default rates per regulatory portfolio, using at least a five-year average annual default rate. Banks must cover key group-wide models approved by SAMA, explain how model scope was determined, state the share of RWA covered, and supplement the flexible-format template with narrative commentary. Mandatory for banks using A-IRB and/or F-IRB, with separate portfolio breakdowns where both approaches are used.

**Regimes:** banking prudential, governance/risk
