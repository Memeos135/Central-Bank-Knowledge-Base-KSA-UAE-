# Change Release Management

A control area within the System Change Management chapter of SAMA's IT governance/IT controls framework, addressing how approved and tested changes are released into production, including use of agreed change windows and a separate approval route for exceptions. It sits alongside adjacent requirements on change governance, change testing (unit, SIT, stress, security and UAT, using sanitized rather than production data) and change security requirements aligned to the SAMA Cyber Security Framework. It binds Member Organizations supervised by SAMA, which must define, approve, implement, communicate and periodically evaluate the process.

**Regimes:** governance/risk
