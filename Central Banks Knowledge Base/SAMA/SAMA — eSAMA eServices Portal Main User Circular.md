# eSAMA eServices Portal Main User Circular

A SAMA circular introducing the eSAMA eServices portal, which digitises SAMA services (e.g. non-objection requests for senior appointments and for launching products and services) for individuals, business and government users, with access via the national single sign-on. It designates the chief executive officer (or equivalent) of each supervised financial institution as the portal's main user, authorised to delegate submission rights, with identity data drawn automatically from the Ministry of Commerce linkage. It binds SAMA-supervised financial institutions, which must comply as written submissions are progressively phased out.

**Regimes:** governance/risk, other
