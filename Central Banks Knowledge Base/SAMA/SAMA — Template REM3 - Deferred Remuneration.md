# Template REM3 - Deferred Remuneration

Template REM3 is the Pillar 3 disclosure of a bank's total outstanding deferred and retained remuneration, completing the remuneration set with Table REMA and Templates REM1 and REM2 under SAMA's Pillar 3 Disclosure Requirements Framework. It applies annually to banks, using the senior management and material risk-taker categories defined in Table REMA, and must be published annually (as soon as possible after the annual report if not simultaneous).

**Regimes:** banking prudential, governance/risk
