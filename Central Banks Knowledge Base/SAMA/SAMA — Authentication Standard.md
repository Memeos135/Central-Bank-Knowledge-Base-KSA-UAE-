# Authentication Standard

Node requiring Member Organisations to define, approve, implement and maintain an authentication standard for customer, employee and third-party credentials and instructions, developed jointly by the Counter-Fraud Department and Cyber Security Team. The standard must reflect both the Fraud Risk Assessment and the Cyber Security Risk Assessment, cover digital and non-digital channels (online, mobile, phone, ATM, branch), and follow a risk-based approach with multi-factor authentication for higher-risk instructions or activity. It cross-refers to identity and access management and electronic banking controls in SAMA's Cyber Security Framework and binds SAMA-supervised Member Organisations.

**Regimes:** governance/risk, payments, consumer protection

### [[SAMA — SAMA Cyber Security Framework|SAMA Cyber Security Framework]] — `references` [EXTRACTED]
- **What this link tells you:** When assessing whether an authentication control set is adequate, do not treat the Authentication Standard as self-contained: it directs member organisations to apply it alongside SAMA's other frameworks and expressly points to the Cyber Security Framework for the underlying cyber security requirements. The two instruments therefore sit in one obligation chain under SAMA's supervisory mandate, with the Framework supplying the governance, policy and control architecture that authentication requirements presuppose. Practically, an authentication design that satisfies the Standard but is not anchored in the entity's Framework-based cyber security policies, standards and risk management will still be exposed on supervisory review.
