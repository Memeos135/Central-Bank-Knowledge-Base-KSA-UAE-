# Template CR9 - IRB Backtesting of PD Per Portfolio

Pillar 3 disclosure template CR9 within SAMA's Pillar 3 Disclosure Requirements Framework, requiring banks to backtest modelled probability of default against realised obligor default rates for each regulatory portfolio, using at least a five-year average annual default rate. It is mandatory only for banks with SAMA approval to use the F-IRB and/or A-IRB approaches, with separate template sets where both approaches are used. Disclosure is annual, flexible in format, and must be accompanied by narrative explaining model scope and the share of RWA covered.

**Regimes:** banking prudential, governance/risk
