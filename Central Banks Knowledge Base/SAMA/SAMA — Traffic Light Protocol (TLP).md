# Traffic Light Protocol (TLP)

Concept node for the Traffic Light Protocol classification scheme as applied under the CTI Principles: all threat information produced by Member Organizations is to be classified using TLP, consistent with the SAMA Cybersecurity Communication Protocols. It governs how collected and produced intelligence is labelled, stored and how far it may be distributed when shared internally or with external parties. Relevant to any question about permissible onward sharing of threat information in the KSA financial sector.

**Regimes:** governance/risk, data/credit info
