# Security Information and Event Management (SIEM)

Covers cyber security event management and the SIEM/monitoring concepts in the SAMA Cyber Security Framework: Member Organizations must define, approve and implement a security event management process to analyse operational and security logs and respond to events, supported by an approved security event monitoring standard keyed to asset classification or risk profile. Requirements include a designated Security Operations Center, trained staff, a restricted SOC workspace, 24x7 monitoring resources, and detection/handling of malicious code and suspicious anomalies; related customer-facing provisions require SMS notification for retail and personal financial transactions and for beneficiary additions, modifications and activations. It binds Member Organizations and interacts with fraud and consumer-notification expectations.

**Regimes:** governance/risk, consumer protection
