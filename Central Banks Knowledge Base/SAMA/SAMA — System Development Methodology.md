# System Development Methodology

Sub-section of the SAMA IT Governance Framework requiring a documented, approved and communicated system development methodology so that development is performed under strict control. It covers development approach, secure coding standards, testing types, version control, quality control, data migration, documentation and end-user training, plus approved low-level system design documents and secure code review (or an independent assurance statement where source code is unavailable). Applies to Member Organizations, including for externally developed applications.
