# Code of Conduct for Problem Loans

A required component of SAMA's Rules on Management of Problem Loans: each bank must adopt a written Code of Conduct setting out its problem-loan resolution process, so that viable borrowers are offered a workout before enforcement. It prescribes documented procedures for borrower communication after missed instalments, information gathering, financial/repayment-capacity assessment, and proposing solutions to cooperating borrowers. Binds all banks licensed under the Banking Control Law, with particular emphasis on fair treatment of MSME borrowers.

**Regimes:** governance/risk, consumer protection, banking prudential
