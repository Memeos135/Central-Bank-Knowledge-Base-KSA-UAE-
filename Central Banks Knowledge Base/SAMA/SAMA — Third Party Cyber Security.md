# Third Party Cyber Security

This node addresses third party cyber security within SAMA's cyber security framework, i.e. expectations that cyber risks arising from external parties and contractual relationships are governed through approved policy, defined responsibilities and compliance with regulatory and contractual obligations. The supplied context anchors it to the framework's policy content requirements, board accountability and the six-level maturity model used for assessment. It binds Member Organizations supervised by SAMA; note the interaction with outsourcing and vendor governance expectations.

**Regimes:** governance/risk
