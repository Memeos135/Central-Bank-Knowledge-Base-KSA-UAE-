# Guidance Manual for Returns Management System

A SAMA user guidance manual explaining how supervised entities access and use the Returns Management System (RMS) portal to complete, validate, submit and, where SAMA raises observations, resubmit supervisory and prudential returns on quarterly and annual cycles. It describes the two portal interfaces (SAMA supervisors and supervised companies), account provisioning by SAMA, notification of open reporting periods, and the finality of submitted returns pending supervisory approval. It is procedural in nature and binds entities subject to SAMA supervision that are required to file regulatory returns.

**Regimes:** governance/risk, banking prudential
