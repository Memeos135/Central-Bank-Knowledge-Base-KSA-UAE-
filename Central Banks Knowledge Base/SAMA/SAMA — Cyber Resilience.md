# Cyber Resilience

Node addressing the cyber/technology resilience dimension of the SAMA BCM Framework, drawing on the framework's definitions (BCM, IT Disaster Recovery, MAO) and its IT DR controls requiring the alternative data centre to carry the same logical, physical, environmental and cyber security controls as the primary site. The framework cross-refers to the SAMA Cyber Security Framework for threat and vulnerability management, and expects cyber scenarios in continuity testing. Binds all member organizations.
