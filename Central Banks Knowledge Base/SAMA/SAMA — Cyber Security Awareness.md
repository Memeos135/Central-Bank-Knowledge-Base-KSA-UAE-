# Cyber Security Awareness

This node covers the cyber security awareness requirement in SAMA's cyber security framework: a defined and approved awareness program must be conducted for staff, third parties and customers of the Member Organization. Its objective is a risk-aware culture in which those groups make effective risk-based decisions protecting the organization's information; the related policy provisions require that relevant stakeholders be made aware of cyber security and expected behaviour. Maturity of this control is measured on the framework's 0–5 scale.

**Regimes:** governance/risk
