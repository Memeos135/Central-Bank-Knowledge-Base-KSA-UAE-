# Cyber Security Maturity Model

This node describes SAMA's cyber security maturity model, a six-level scale (0 non-existent through 5) used to measure a Member Organization's attainment against the framework's control domains, with higher levels conditional on meeting all preceding level criteria. It is the measurement lens SAMA applies when assessing compliance, and it links to the required contents of the board-endorsed cyber security policy and to defined cyber security roles and responsibilities. It binds Member Organizations supervised by SAMA and engages Board-level accountability.
