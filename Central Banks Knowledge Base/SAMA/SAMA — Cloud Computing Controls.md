# Cloud Computing Controls

A subdomain of SAMA's Cyber Security Framework requiring Member Organizations to define, approve, implement and monitor cyber security controls within a cloud computing policy and process, with periodic measurement of effectiveness. It is expressly scoped to hybrid and public cloud services and does not apply to private (internal) cloud, and it sits alongside the adjacent outsourcing subdomain, which requires prior SAMA approval for material outsourcing and compliance with the SAMA outsourcing circular. Compliance is assessed against the framework's six-level cyber security maturity model through self-assessment and SAMA review.
