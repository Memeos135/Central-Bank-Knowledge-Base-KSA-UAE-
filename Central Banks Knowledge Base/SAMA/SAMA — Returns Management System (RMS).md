# Returns Management System (RMS)

Describes the Returns Management System, SAMA's digital portal through which supervised entities submit defined supervisory and prudential return templates and through which SAMA supervisors review, accept or return them; it includes a user guidance manual and the accompanying circular updating supervisory return forms for money exchange centres. It sets submission mechanics and deadlines (monthly sales/purchases returns within a set period after month-end; quarterly currency, largest-customer, counterfeit-currency and staff data within the stated days after quarter-end), completion and validation duties, and resubmission where SAMA raises observations. It binds entities supervised by SAMA required to file returns, notably money exchange centres under the Exchange Business Rules.

**Regimes:** governance/risk, other
