# SAMA Cyber Security Framework v1.0

SAMA's Cyber Security Framework, setting principles, objectives and control considerations for cyber security governance and defining a six-level maturity model (0–5) used to measure and benchmark compliance. It specifies the required content of a cyber security policy, board-level ultimate responsibility including budget and approvals, and the allocation of cyber security roles and responsibilities across the organisation. It binds Member Organizations supervised by SAMA.
