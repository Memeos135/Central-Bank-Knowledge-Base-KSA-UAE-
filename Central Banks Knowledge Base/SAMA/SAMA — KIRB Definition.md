# KIRB Definition

A concept node for KIRB — the IRB capital requirement on the underlying pool of a securitization, the core input to the securitization internal-ratings-based approach (SEC-IRBA), including its decomposition into default-risk and dilution-risk components and its use with pool and tranche parameters (N, LGD, attachment/detachment points, maturity). Illustrated by worked examples on recognising dilution risk in SEC-IRBA. Applies to SAMA-supervised banks permitted to use IRB approaches for securitized underlying exposures.

**Regimes:** banking prudential
