# API Design Principles

Node capturing the API design and development expectations in the CBUAE enabling-technologies guidelines, including design elements such as accessibility, interoperability, reuse, independence, extensibility, stability, privacy by design and transparency. It also addresses documented technical specifications, encryption of Personal Data in transit and at rest, access management, secure credential storage, and multi-factor authentication for customer access to API-enabled online services. Applies to Institutions and, where relevant, API Providers developing APIs.

**Regimes:** governance/risk, data/credit info, payments
