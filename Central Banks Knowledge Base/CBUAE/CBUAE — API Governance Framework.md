# API Governance Framework

Node on the API governance expectations in the CBUAE Guidelines for Financial Institutions adopting Enabling Technologies. It expects a documented governance framework covering roles and division of duties between the Institution, API Provider and API developer, policies and controls across the API Lifecycle, change management and performance monitoring, pre-publication and ongoing testing (load, stress, conformance monitoring), and a framework to assess, monitor, report and mitigate API-related risks. Binds Institutions using or publishing APIs; expressed as supervisory expectations rather than prescriptive rules.

**Regimes:** governance/risk, payments
