# Basel Framework

Concept node for the Basel framework as referenced in CBUAE rules, used to define "eligible capital" (regulatory capital) at entity level for branches of foreign banks, as implemented in the bank's home jurisdiction. It functions as an external reference standard rather than a standalone CBUAE obligation, and is relevant where UAE capital tests defer to home-state regulatory capital definitions.

**Regimes:** banking prudential
