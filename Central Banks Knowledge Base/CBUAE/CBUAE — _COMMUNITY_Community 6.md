# API & Authentication Framework

## Why this community

Controls governing application programming interfaces and the authentication of users and identities, including where API activity is outsourced and where customer data is exposed through interfaces.

## How members connect

- The API governance framework is the parent obligation; design principles and management/monitoring are its build-stage and run-stage counterparts.
- API governance cross-references data protection and the Outsourcing Service Provider definition, pulling third-party and confidentiality regimes into the API perimeter.
- Authentication forms a nested chain: identity lifecycle management sets enrolment/change/revocation duties, multifactor authentication is the required strength, and biometric authentication is a specific factor type subject to its own conditions.
- API design principles reference multifactor authentication, linking interface design obligations to access-control requirements rather than treating them as separate regimes.
