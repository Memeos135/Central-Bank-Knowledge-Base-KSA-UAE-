# Sampling Methodology

Concept node covering the sampling element of the SCF field review under the CBUAE Guidance Note. It expects the Shari'ah Compliance Function to adopt an objective, robust sampling methodology with a defined minimum sample proportion so that reviewed transactions fairly represent the review period, and to enlarge the sample where there is reasonable doubt whether an identified Shari'ah non-compliance incident is isolated or systemic. The trigger conditions for expanding samples must themselves be set out in the institution's methodology; generic guidance sits in an appendix.
