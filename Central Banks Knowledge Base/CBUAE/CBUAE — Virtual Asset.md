# Virtual Asset

Defined-term node for "Virtual Asset" as used in the CBUAE Payment Token Services Regulation, where a Payment Token is a Virtual Asset that purports to maintain a stable value by reference to a fiat currency (or another token in the same fiat currency). It marks the perimeter between CBUAE-supervised payment token activity and virtual asset activity licensed by SCA or a Local Licensing Authority, including information-sharing with those regulators and the post-Transition Period disapplication of the Retail Payment Services and Card Schemes Regulation and the Stored Value Facilities Regulation to crypto-asset/virtual asset activities.

**Regimes:** payments, other, governance/risk
