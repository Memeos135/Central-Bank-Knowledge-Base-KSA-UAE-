# Authorized Agents Accountability

Concept node on accountability for Authorized Agents: Licensed Financial Institutions must authorize agent access to Consumer Personal Data in writing, monitor it regularly and restrict it to the purpose of access, and include confidentiality and non-disclosure provisions in all outsourcing contracts. Authorized Agents must report significant Personal Data breaches to the institution's Data Management and protection function, and the institution's duty to protect Consumer Data extends to the acts of all Authorized Agents. Agents also act as a receiving point for Unauthorized Transaction reports, which triggers the institution's handling obligations.

**Regimes:** consumer protection, data/credit info, governance/risk
