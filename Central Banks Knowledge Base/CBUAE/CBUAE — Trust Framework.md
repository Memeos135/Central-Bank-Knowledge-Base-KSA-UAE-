# Trust Framework

This node identifies the Trust Framework, one of the three components of the UAE Open Finance Framework alongside the API Hub and Common Infrastructural Services, with its minimum contents set out in Schedule 1 of the Open Finance Regulation. It must include a Participants Directory for validating participants and secure information exchange, identity and access management for enrolled market participants (enrolment, contact management, digital certificate and application registration/validation), and digital certificates for secure participant-to-participant communication. It is relevant to all Licensees, Open Finance Providers and the API Hub operating within the framework.

**Regimes:** payments, data/credit info, governance/risk
