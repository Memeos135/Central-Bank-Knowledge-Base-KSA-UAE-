# DLT Governance Framework

Guidance setting out the governance framework institutions are expected to approve and document before relying on Distributed Ledger Technology, covering platform and node ownership, the operating model (e.g. consortium vs single institution), participant and validator rules, access approval for ledger data, key management, consensus protocol and off-chain procedures. It also allocates roles and responsibilities across the core design/operation group, qualified users, participants and third parties including outsourcing service providers, and requires audit-ready evidence, logs, off-chain/on-chain linkage records and retention of DLT code and updates. Binds financial institutions deploying DLT applications.

**Regimes:** governance/risk, other
