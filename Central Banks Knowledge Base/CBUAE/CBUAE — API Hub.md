# API Hub

This node concerns the API Hub, the separately licensed operator at the centre of the UAE Open Finance Framework, which aggregates and standardises participant APIs and provides the participant integration layer. It sets licensing conditions and prudential-style obligations: a capital funding plan approved by the Central Bank, a minimum capital requirement the Central Bank may vary, prior approval for capital changes and no objection for profit or dividend distributions, plus immediate notification and a remediation plan on breach. It also restricts the API Hub to licensed activities, limits it to processing consented User Data only (no Personal or Confidential Data), and requires data protection controls and security incident/complaint procedures.

**Regimes:** payments, data/credit info, banking prudential, governance/risk
