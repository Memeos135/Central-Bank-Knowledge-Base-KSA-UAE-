# FATF Standards

Concept node for the Financial Action Task Force, cited in CBUAE instruments (notably the Stored Value Facilities Regulation) as the inter-governmental standard-setter for anti-money laundering and counter-terrorist-financing standards. It functions as a definitional and interpretive reference rather than a directly binding instrument: licensees are pointed to FATF outputs, including risk-based approach guidance for virtual assets and virtual asset service providers, when calibrating AML/CTF controls. Relevant to any licensee whose CBUAE obligations are framed by reference to international AML/CTF standards.

**Regimes:** AML/CTF, payments, governance/risk
