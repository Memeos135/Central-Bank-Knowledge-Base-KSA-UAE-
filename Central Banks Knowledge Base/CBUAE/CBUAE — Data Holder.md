# Data Holder

Defined term in the CBUAE Open Finance Regulation meaning a Licensee that holds User Data. The node covers the Data Holder's obligations when a User uses Data Sharing: to communicate the requested User Data, to treat the request as if made directly by the User, and to communicate securely with the Data Sharing Provider; it also frames the counterpart duties of Data Sharing Providers, including the prohibition on processing Sensitive Data. Binds UAE-licensed institutions holding User Data; scope is limited to User Data and does not displace other personal data protection laws.

**Regimes:** data/credit info, payments, consumer protection, governance/risk
