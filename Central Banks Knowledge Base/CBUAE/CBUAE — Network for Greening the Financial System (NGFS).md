# Network for Greening the Financial System (NGFS)

Reference node for the Network for Greening the Financial System, an international grouping of central banks and supervisors whose work is cited as a source standard behind the climate-related financial risk principles. It is relevant as interpretive background for supervisory expectations on climate risk governance, scenario analysis and risk management, not as a binding instrument. No direct obligations flow from this node itself.

**Regimes:** governance/risk, other
