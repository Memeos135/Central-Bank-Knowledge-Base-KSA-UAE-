# TTC LGD Modelling

Guidance on through-the-cycle LGD modelling in the CBUAE Model Management Guidance, covering the loss components framework, treatment of bimodal LGD distributions (cautioning against using an average between peaks at facility level) and logical consistency properties such as final LGD not exceeding unsecured LGD and decreasing with collateral. These logical features must be tested during model validation. Binds CBUAE-licensed institutions building credit loss models.

**Regimes:** governance/risk, banking prudential
