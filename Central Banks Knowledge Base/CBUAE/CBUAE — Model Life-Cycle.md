# Model Life-Cycle

Concept node for the model life-cycle as the organising structure of the MMS, spanning design, development, calibration, validation, monitoring and decommissioning, together with the defined terms that drive it (model, model calibration, model complexity, materiality, Model Risk). It also frames MMS scope: all model types used to support decision-making, including risk, pricing, valuation and stress-testing models, plus transitional remediation planning and ongoing reporting to the CBUAE. Binds institutions subject to the MMS across every stage at which models are built, used or relied on.

**Regimes:** governance/risk, banking prudential
