# Default Rate Estimation

Guidance on how institutions should compute observed default rates as the empirical basis for PD modelling and macro model construction. It requires estimation at portfolio level and, where feasible, at rating-grade level (with data-based justification if only pool-level estimation is used), using a 12-month observation window with performing obligors in the denominator and obligors defaulting at least once in the numerator. It also requires a consistent default definition across PD and LGD estimation, including for restructured facilities, with retroactive changes approved by the Model Oversight Committee and the risk management committee.

**Regimes:** banking prudential, governance/risk
