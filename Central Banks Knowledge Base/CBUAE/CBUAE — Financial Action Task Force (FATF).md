# Financial Action Task Force (FATF)

Concept node for the Financial Action Task Force as the international AML/CFT standard-setter referenced across several CBUAE guidance instruments. In the cited material it sits within guidance on suspicious transaction reporting practice — report typology (STR, SAR, AIF, AIFT via goAML), submission triggers and the content expected in a report narrative. Useful as a cross-reference point rather than a binding instrument in itself; the binding obligations sit in the UAE federal AML framework and CBUAE guidance.

**Regimes:** AML/CTF, governance/risk

### [[CBUAE — FATF Recommendation 7 (TFS related to PF)|FATF Recommendation 7 (TFS related to PF)]] — `references` [EXTRACTED]
- **What this link tells you:** For any question about targeted financial sanctions tied to DPRK or Iran proliferation, this link tells you the guidance defers to FATF Recommendation 7 for the substantive TFS standard, so the analysis sits in the sanctions/TFS regime rather than general AML/CFT CDD. That matters because TFS duties are absolute (asset freeze, no-dealing, prompt implementation) and are not risk-based, unlike the surrounding PF risk-management expectations. Read the two together but do not let risk-based language dilute a freeze obligation; verify the operative domestic TFS instrument, since Recommendation 7 itself is a standard, not directly applicable law.
