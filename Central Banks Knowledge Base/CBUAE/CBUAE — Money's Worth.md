# Money's Worth

Definitional node anchoring "Money's Worth" and related defined terms in the CBUAE SVF Regulation, including Float, Licence/Licensee, Operating Rules, Senior Management, Single-purpose Stored Value Facility, State and Stored Value Facility. Money's Worth extends the value paid into an SVF beyond cash to items such as values, points, Crypto-Assets and Virtual Assets, which determines whether a scheme falls within the SVF perimeter. Relevant to anyone testing whether a product is a licensable SVF.

**Regimes:** payments, other
