# Open Finance Framework

## Why this community

The architectural and governance layer of the Open Finance regime: the central framework instrument and the shared infrastructure (API hub, trust framework, common services) through which regulated open finance participation is delivered.

## How members connect

- The Open Finance Framework is the parent instrument; the API Hub, Trust Framework and Common Infrastructural Services are its mandated components, so obligations flow downward from the framework to each infrastructural element.
- Use of the central API hub engages the outsourcing regulation circular, meaning reliance on shared infrastructure does not displace the participant's own accountability for outsourced functions.
- The infrastructure is benchmarked against international financial market infrastructure principles, which supplies the resilience, governance and access-criteria expectations.
- This cluster is the institutional counterpart to the participant-role cluster on data sharing and service initiation.
