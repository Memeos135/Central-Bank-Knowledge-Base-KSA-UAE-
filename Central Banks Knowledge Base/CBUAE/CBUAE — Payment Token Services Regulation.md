# Payment Token Services Regulation

Instrument node for the CBUAE Payment Token Services Regulation, which defines and regulates payment token activities — payment token issuing, custody and transfer, and conversion — and the persons performing them by way of business. It contains the core definitional architecture (Payment Token Issuer, Dirham vs Foreign Payment Token Issuer, Payment Token Conversion Provider, Payment Token Custodian and Transferor, Payment Token Data, Payment Token Transfer), including the rule that where a token is first passed to a distributor for onward sale, the distributor is treated as performing the issuing. It also prohibits interest-like benefits tied to holding periods and empowers the Central Bank to cap volumes, values or customer numbers, or to restrict further sales, transfers or onboarding.

**Regimes:** payments, governance/risk, other

### [[CBUAE — Payment Token Issuer|Payment Token Issuer]] — `references` [EXTRACTED]
- **What this link tells you:** Whether an entity is captured turns on the defined term Payment Token Issuer as scoped by the Regulation, and that scope is broader than the customer-facing sale or transfer. The Regulation attaches responsibility for token generation and for the supporting technology to the issuer, so functions delegated to a technology provider still sit with the licensed issuer as a matter of accountability. The consequence is that a firm cannot narrow its perimeter by outsourcing minting or infrastructure; classify the whole activity chain against the defined term before concluding a licence is not required.
