# Data Sharing

Defined activity under the CBUAE Open Finance Regulation: an online service providing a User with consolidated User Data relating to one or more Accounts. The node sets the governing conduct rules — provision only on the User's explicit consent and instructions, a prohibition on processing Sensitive Data even with consent, protection and secure transmission of personalised security credentials, self-identification to the Data Holder and User, and a purpose limitation on use, access or storage of information except where required by UAE law. It binds Data Sharing Providers and, correspondingly, Data Holders.

**Regimes:** data/credit info, payments, consumer protection, governance/risk
