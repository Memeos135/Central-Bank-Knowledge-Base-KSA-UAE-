# IOSCO CRA Code of Conduct

Concept node on the IOSCO Code of Conduct Fundamentals for Credit Rating Agencies as a benchmark in the Central Bank's eligibility criteria for External Credit Assessment Institutions. It requires an ECAI to adopt and follow a code of conduct consistent with the IOSCO CRA Code and to be supervised on an ongoing basis by a competent authority with a consistent regime and a registration system, alongside criteria on transparency, disclosure, no abuse of unsolicited ratings and cooperation with the supervisor. It binds ECAIs seeking or holding recognition, and indirectly banks relying on their ratings.

**Regimes:** banking prudential, governance/risk
