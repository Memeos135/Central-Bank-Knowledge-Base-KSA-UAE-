# Crypto-Asset

Definitional node situating Crypto-Asset alongside related defined terms — Virtual Assets, Virtual Asset Service Providers, Virtual Asset Token — and its use within the Money's Worth definition for stored value facilities. It matters for scope: a Virtual Asset Token is a type of Crypto-Asset, and Crypto-Assets or Virtual Assets can constitute value topped up, held or redeemed on an SVF account. Relevant to Payment Service Providers, SVF issuers and any person assessing whether crypto-linked value falls inside the retail payments perimeter or the VASP/FATF perimeter.

**Regimes:** payments, AML/CTF, other
