# Transaction Monitoring and STR (Payment Sector)

Section of the CBUAE payment-sector AML/CFT guidance on ongoing transaction monitoring and suspicious transaction reporting. LFIs must monitor all customer activity using information gathered through CDD, calibrated to customer, product, channel and geographic risk, and must report to the UAE FIU whenever there are reasonable grounds to suspect proceeds of crime or a crime-related transaction or attempted transaction, regardless of amount. It stresses that in intermediated payment chains each LFI remains responsible for monitoring the transactions it processes, using the information available to it.

**Regimes:** AML/CTF, payments
