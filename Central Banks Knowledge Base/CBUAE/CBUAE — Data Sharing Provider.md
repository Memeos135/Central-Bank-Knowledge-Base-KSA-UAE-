# Data Sharing Provider

This node sets the conduct obligations of a Data Sharing Provider, a category of Open Finance Provider licensed to undertake Data Sharing. It may provide Data Sharing only on the User's explicit consent and instructions, must not Process User Data that is Sensitive Data even with explicit consent, must keep personalised security credentials (PINs, passwords) inaccessible to parties other than the issuer and transmitted through secure channels, must identify itself and communicate securely with the Data Holder and User, and must not use, access or store information for any purpose other than the User-requested service except where required by UAE law.

**Regimes:** payments, data/credit info, consumer protection
