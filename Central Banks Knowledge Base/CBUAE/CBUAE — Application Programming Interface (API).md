# Application Programming Interface (API)

Defines Application Programming Interface (API) and related terms (API Lifecycle, API Provider) within the joint CBUAE/SCA/DFSA/FSRA Guidelines for Financial Institutions adopting Enabling Technologies, and sets expectations for API design, architecture, security and governance. It distinguishes Private, Partner, Open and Composite APIs and lists design attributes such as accessibility, interoperability, privacy by design and stability. Addressed to Institutions in scope of the Guidelines as supervisory expectations (largely 'should'-level guidance), including where API use is outsourced.

**Regimes:** governance/risk, data/credit info, other
